# NeuroConnect 🧠🌿

**NeuroConnect** é um protótipo de aplicativo multiplataforma para atendimento terapêutico (psiquiatria e psicologia), focado em bem-estar emocional, registro de sentimentos e conexão humanizada com profissionais.

## 🧩 Telas implementadas

- `index.html`: Tela de login
- `home.html`: Tela inicial do paciente
- `journal.html`: Diário emocional
- `style.css`: Estilo com layout natural e acolhedor
